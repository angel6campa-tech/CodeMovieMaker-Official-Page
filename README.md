
# 🎬 CodeMovieMaker

**Your creativity. Your code. Your movie.**

CodeMovieMaker is a 3D animation and movie-making studio designed to let creators build scenes, create characters, animate objects and produce cinematic experiences.

## 🚀 Editions

### 🔹 CodeMovieMaker NORMAL
The standard edition for creators who want to explore 3D animation and create their own scenes.

### 💎 CodeMovieMaker PLUS
An enhanced edition with additional tools and features for a more advanced creative workflow.

## ✨ Features

- 🎥 3D scene creation
- 🧍 Character and avatar support
- 🏙️ 3D objects and environments
- 🎞️ Animation and keyframes
- 💻 HTML, CSS and JavaScript editor
- 🎨 Customizable scenes
- 📹 Video recording
- 💾 Project saving

## 🛠️ Technology

- HTML
- CSS
- JavaScript
- Three.js
- Electron (PLUS desktop edition)
